MARÍLIAJÁ — PACOTE DO PORTAL

Arquivos estáticos para GitHub Pages, com Firebase Firestore para notícias compartilhadas.

ATUALIZAÇÃO EDITORIAL INCLUÍDA
- Capa com cotação do dólar e clima atual de Marília via serviços online.
- Última notícia em destaque e notícias organizadas por categoria.
- Cada notícia abre em página individual (noticia.html).
- Botões de compartilhamento WhatsApp, Facebook e cópia de link para Instagram.
- Páginas Quem Somos, Políticas de Privacidade, Termos de Uso e Contato.
- Espaços reservados para anúncios na capa e nas páginas de notícia.
- TV MARÍLIAJÁ para vídeos do YouTube cadastrados pelo painel.
- Editor com negrito, alinhamento, inserção de link, imagem e vídeo do YouTube.

PUBLICAÇÃO NO GITHUB
1. Extraia o ZIP. Envie os arquivos e pastas para a raiz do repositório MARILIAJA-NOVO, substituindo os arquivos de mesmo nome e adicionando os novos.
2. Mantenha o arquivo assets/js/firebase-config.js já configurado com sua apiKey real; se usar o ZIP de atualização gerado nesta conversa, confira esse arquivo antes de enviar para garantir que a chave real não foi substituída.
3. O GitHub Pages deve continuar usando a branch main e a pasta /(root).
4. As regras do Firestore publicadas anteriormente continuam compatíveis: leitura pública de noticias e escrita por administradores ativos.

CONTATO POR E-MAIL
A página contato.html usa FormSubmit para encaminhar as mensagens para portalmariliaja@gmail.com. Na primeira submissão, o serviço poderá enviar uma mensagem de ativação para esse endereço. É necessário abrir o e-mail e confirmar a ativação. O formulário não deve ser considerado ativo até esse passo ser concluído e testado.

COTAÇÃO E CLIMA
Os dados são carregados no navegador por APIs públicas. A disponibilidade pode variar; se o serviço estiver indisponível, a página mostrará uma mensagem de indisponibilidade.

ANÚNCIOS
Os espaços marcados PUBLICIDADE são apenas áreas reservadas para inserir banners ou códigos de uma plataforma de anúncios quando você tiver esses materiais. Não há anúncios ativos ainda.

VÍDEOS E EDITOR
No painel, selecione a categoria TV MARÍLIAJÁ e preencha o campo do link do YouTube. Para vídeos dentro de uma notícia, use Inserir vídeo YouTube. Imagens no conteúdo usam URL pública.
